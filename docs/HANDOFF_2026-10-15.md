## Per-machine setup on a new computer

- `conda` env `ML` with `pip install modal`; `modal token new` (workspace cortex-technologies).
- Modal secret `huggingface-secret` already holds a valid `HF_TOKEN` (fine-grained, write).
- `.env` is not in git: copy it by hand (or recreate from `.env.example`).
- Claude Code memory lives in `~/.claude/projects/-<path-to-repo>/memory/`; copy that folder
  if you want the agent to remember the pitfalls listed in `hishab-v3-results.md`.
- For kiln on the Mac: `cmake --preset host && cmake --build --preset host -j`, then download the
  GGUF from the HF repo above into `kiln/models/`.
